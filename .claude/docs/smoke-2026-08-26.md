## Defects found: none in the product

Two "failures" during the run were faults in my own smoke, not in Kuyash, and are
recorded because a green matrix that hid them would be worth less:

1. The tenant check hard-coded `/runs/1` as "another workspace's run". Run 1 is in
   *this* workspace, so a correct 200 read as a leak. The check now DISCOVERS a run
   outside the session's workspace instead of assuming one.
2. The kill-switch check POSTed no `state`, and the handler is an explicit
   set-to-value, not a blind toggle — so it set OFF and I read it as "toggle did
   nothing". Re-run with `state=on`/`state=off`: correct both ways.

One cosmetic note, not fixed (no user-visible effect): `compliance.warned` carries
`reason: ""`, because a warn's cause is the slop score and `reasons[]` holds block
reasons only. The rendered sentence uses `{slop}`, not `{reason}`, so nothing empty
reaches a screen.
